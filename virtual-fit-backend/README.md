# VOEUX® VIRTUAL FIT — ML Computer Vision API

AI-free, open-source ML backend powered by **PyTorch + Google OWL-ViT (Apache 2.0) + OpenCV + FastAPI** for [VOEUX® Electronics](https://voeuxtechnologies.in/).

## Endpoints
- `GET /api/virtual-fit/health`
- `GET /api/virtual-fit/products`
- `POST /api/virtual-fit/detect-corners`
- `POST /api/virtual-fit/detect-and-fit`
- `POST /api/virtual-fit/refit`
